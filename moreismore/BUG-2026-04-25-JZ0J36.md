## Beschreibung

# Implement dedicated Theme Editor page in Settings with live preview

**Severity:** medium
**Tags:** feature, ui, settings, ux

## Summary
Implement a standalone Theme Editor within the settings menu to enable real-time color customization and a full-app preview functionality.

## Steps to Reproduce
1. 1. Open the Info/Settings window.
2. 2. Navigate to the new Theme Editor page.
3. 3. Enter Edit Mode.
4. 4. Modify various theme color parameters.
5. 5. Observe the live preview across the entire application.

## Expected Behavior
A dedicated settings page should allow real-time adjustment of all theme colors with a comprehensive, app-wide live preview.

## Actual Behavior
There is currently no dedicated Theme Editor page in settings that supports live color customization and global application preview.
