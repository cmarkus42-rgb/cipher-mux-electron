# BUG-2026-04-25-1YURWJ — Feature Request: Dateien/Bilder in Sessions droppen oder pasten

**Status:** OPEN
**Bereich:** Renderer / Terminal / SessionCell
**Schwere:** Feature Request

## Beschreibung

Dateien und Bilder sollten per Drag & Drop oder Paste in Terminal-Sessions eingefuegt werden koennen. Aktuell ignoriert xterm.js beides — es unterstuetzt nativ nur Text-Input.

## Gewuenschtes Verhalten

- **Datei droppen auf SessionCell:** Dateipfad als Text in die Session einfuegen (z.B. `/Users/cipher/foo.png`)
- **Bild pasten (Cmd+V mit Bild im Clipboard):** Bild temporaer speichern, Dateipfad einfuegen
- **Mehrere Dateien:** Pfade space-separated oder newline-separated

## Moegliche Umsetzung

1. `onDrop`-Handler auf SessionCell/TerminalPane: `e.dataTransfer.files` auslesen, Pfade extrahieren, via `api().terminal.write()` in die Session senden
2. `onPaste`-Handler: Clipboard auf `image/*` Items pruefen, via IPC temporaer speichern (`app.getPath('temp')`), Pfad zurueck an Terminal senden
3. Optional: Pfade shell-escapen (Leerzeichen etc.)

## Kontext

Session-zu-Session Copy/Paste (Text) funktioniert. NoteEditor Copy/Paste gefixt in BUG-2026-04-25-1FP9VH. Dieses Feature erweitert die Terminal-Interaktion um Datei-basierte Inputs.
