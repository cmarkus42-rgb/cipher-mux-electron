## B.7 — Highlight-Design: Border-Glow statt flaechiger Glow

**Prioritaet:** MUST

### Problem
Glow-Effekt ueberstrahlt Button-Beschriftung. Helligkeit uneinheitlich.

### Aktuelles CSS (components.css Z.2409-2415)
```css
.highlight-overlay--glow {
  box-shadow:
    0 0 8px 2px rgba(79, 195, 247, 0.6),
    0 0 20px 4px rgba(79, 195, 247, 0.3),
    inset 0 0 4px 1px rgba(79, 195, 247, 0.15);
  border: 1px solid rgba(79, 195, 247, 0.5);
}
```

### Neues Design: Border-Glow
```css
.highlight-overlay--glow {
  /* NUR Raender leuchten, kein inset */
  border: 2px solid rgba(79, 195, 247, 0.8);
  box-shadow:
    0 0 6px 1px rgba(79, 195, 247, 0.5),
    0 0 12px 2px rgba(79, 195, 247, 0.2);
  /* KEIN inset, KEIN flaechiger Glow */
  background: transparent;
  animation: highlight-pulse 1.5s ease-in-out infinite;
}
```

### Outline-Style muss sich SICHTBAR unterscheiden
```css
.highlight-overlay--outline {
  /* Statische helle Border, KEIN Pulsieren */
  border: 2px solid rgba(79, 195, 247, 0.9);
  box-shadow: none;
  background: transparent;
  animation: none; /* Kein Pulsieren — das ist der Unterschied */
}
```

**Glow = pulsierende Border, Outline = statische helle Border ohne Pulsieren.**

### Einheitliche Helligkeit
HighlightOverlay.tsx berechnet DOMRect-Position. Die CSS-Werte muessen fuer alle Groessen gleich aussehen (keine unterschiedliche Helligkeit bei kleinen vs. grossen Elementen).

**Akzeptanzkriterien:**
- [ ] Glow: Raender leuchten/pulsieren, Inhalt bleibt unberuehrt
- [ ] Outline: Statische helle Border ohne Pulsieren
- [ ] Glow und Outline sind SICHTBAR unterschiedlich
- [ ] Einheitliche Helligkeit bei allen Targets

## G.4 — Context-%-Anzeige als Farbbalken

**Design-Entscheidung (steht):**

### Visuell
- Ladebalken von links nach rechts hinter der Schrift im Session-Header
- Farbverlauf: Gruen 0-25% → Gelb 26-40% → Orange 41-55% → Rot 56%+
- 0% = leer, 65% angezeigt = komplett gefuellt (upstream-Bug: angezeigter Wert < real)
- Halbtransparenter Layer (15-20% Opacity), dezent
- Keine Prozentzahl mehr

### Implementierung
In SessionCell.tsx: Session-Header bekommt einen `::before` Pseudo-Element oder ein zusaetzliches `<div>` mit:
- `width: ${Math.min(contextPercent / 65 * 100, 100)}%`
- `background-color` basierend auf Breakpoints
- `opacity: 0.15-0.20`
- Hinter dem Text (z-index niedriger als Text)

### Akzeptanzkriterien
- [ ] Farbbalken im Session-Header sichtbar
- [ ] Farbe wechselt korrekt an Breakpoints
- [ ] Text bleibt gut lesbar
- [ ] 65% angezeigt = volle Breite
