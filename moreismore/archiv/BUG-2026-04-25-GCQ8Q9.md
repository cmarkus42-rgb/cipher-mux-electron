# Implement i18n support for English and future language scalability

**Severity:** high
**Tags:** feature-request, i18n, localization, frontend

## Summary
Implement an internationalization framework for the frontend to support English and future expansion, while maintaining English as the standard for all backend storage.

## Steps to Reproduce
1. 1. Open the application interface.
2. 2. Attempt to locate or switch to the English language setting.
3. 3. Observe that only German is currently available.

## Expected Behavior
The frontend should support English and be architected to allow for the easy integration of additional languages.

## Actual Behavior
The application is currently limited to the German language in the frontend.
