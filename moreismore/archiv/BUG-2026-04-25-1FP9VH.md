# BUG-2026-04-25-1FP9VH — Copy/Paste NoteEditor nach Session broken

**Status:** FIXED
**Bereich:** Renderer / NoteEditor / CodeMirror 6
**Schwere:** Medium — Clipboard zwischen CM6 und xterm.js nicht funktional

## Symptom

Cmd+C im NoteEditor (CodeMirror 6) kopiert nichts aufs System-Clipboard. Paste von NoteEditor in eine Terminal-Session schlaegt fehl. Session-zu-Session Copy/Paste funktioniert normal.

## Root Cause

Electron's Menu-Role `{ role: 'copy' }` ruft `webContents.copy()` auf, was die DOM Selection API nutzt. CodeMirror 6 synchronisiert seine interne Selection nicht immer mit der DOM Selection (Performance-Optimierung). Ergebnis: Chromium-Level Copy liest leere/falsche Selection.

Gleiches Problem bei Paste: `{ role: 'paste' }` triggered `webContents.paste()`, was ein DOM-Paste-Event feuert — aber CM6 faengt es nicht immer zuverlaessig ab.

## Fix

DOM-Level Keyboard-Handler (capture phase) im NoteEditor, der Cmd+C/V/X abfaengt bevor Electron's Menu-Accelerator greift:

- **Cmd+C:** Liest CM6's Selection direkt via `view.state.sliceDoc()`, schreibt via `navigator.clipboard.writeText()`
- **Cmd+V:** Liest via `navigator.clipboard.readText()`, inserted via `view.dispatch(replaceSelection())`
- **Cmd+X:** Wie Copy + loescht Selection
- **Cmd+S:** Wie vorher (Save + Auto-Tag)
