# Kompakte Darstellung der Hintergrundsessions

## Beschreibung

Hintergrundsessions in der Sidebar sollen zwei Darstellungsmodi haben:

### Minimalmodus (Default)

- Maximal 2 Zeilen pro Session (aktuell 5)
- Zeile 1: Anzeigename
- Zeile 2: Token-Usage + Working-Directory (nur Endverzeichnis, nur wenn es vom Anzeigenamen abweicht)

### Detailmodus (per Klick)

- Einfacher Klick auf eine Session klappt sie auf die jetzige 5-Zeilen-Detailansicht auf
- Detailansicht bleibt wie sie ist — die ist gut

### Doppelklick

- Oeffnet die Session (Verhalten wie bisher)

## Kontext

Die aktuelle 5-Zeilen-Darstellung pro Session nimmt zu viel Platz in der Sidebar ein. Bei vielen Hintergrundsessions wird die Liste unuebersichtlich.
