## Beschreibung

# Refactor project selection to folder-picker and integrate notes/favorites

**Severity:** medium
**Tags:** ui, refactor, ux

## Summary
Replace the manual project list with a folder-picker-based system to unify projects and sessions, adding support for favorites and integrated notes functionality.

## Steps to Reproduce
1. 1. Launch the application.
2. 2. Navigate to the project selection interface.
3. 3. Observe the current reliance on a manually updated, persistent list of projects.

## Expected Behavior
Project selection should use an integrated folder picker that allows selecting a directory, opening a shell, and optionally launching Claude (with --resume support), while also supporting favorites and integrated notes.

## Actual Behavior
The current system uses a persistent project list that requires manual updates and lacks seamless integration with folder-level selection.
