# v0.11 Wave 3.1 — Anforderungspaket

> Basiert auf manuellem Test-Report vom 2026-04-26 (14 PASS, 25 FAIL, 20 nicht getestet).
> Ziel: Alle kritischen und hohen Bugs fixen, mittlere/niedrige wo moeglich.

## Projektziel

Die in Wave 3 ausgelieferten Features (LauncherCell, Voice, Tags, MCP Control, Sidebar Polish) funktionsfaehig machen. Der Test-Report zeigt, dass mehrere Feature-Bloecke komplett kaputt oder nicht aktiv sind. Diese Wave fixt die Bugs und schliesst die Luecken.

## Zielgruppe

cipher (Solo-User, Desktop-App cipher-mux-electron)

## Tech-Stack / Constraints

- Electron + React + TypeScript
- xterm.js fuer Terminal-Rendering
- tmux als Session-Backend
- Claude Code als AI-Backend (claude CLI)
- MCP-Server (cipher-mux) fuer Session/Task/Notes-Management
- Brutalist Design-Theme
- Kein git push durch Worker — nur lokale Commits

## Kern-Entscheidungen (vorab getroffen, Level 1-2)

1. **--resume raus** — User hat explizit gesagt, immer frisch starten (B11)
2. **Voice nur via COM-Button** — User will Voice-Preset nicht im Grid-Popup (FR2)
3. **Overlay statt in-cell** — Popups sollen schweben, nicht in Zelle gerendert (B13)
4. **Entity-Farben reaktivieren** — waren da, sind beim Refactor rausgeflogen (B21)
5. **Session-Restore-Dialog** — User will gefragt werden, nicht Auto-Restore (FR5/B06)
