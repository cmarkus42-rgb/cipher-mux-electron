# i18n — Adding New UI Strings

## Quick Start

1. Add the key + English text to `src/renderer/locales/en.json`
2. Add the key + German text to `src/renderer/locales/de.json`
3. Use `t('your.key')` in your component

## Key Convention

Keys follow the pattern `component.element.action`:

```
statusBar.sidebar          → component: StatusBar, element: sidebar button
bugreport.placeholder      → component: BugreportDialog, element: textarea placeholder
hub.setupTitle             → component: HubSetupDialog, element: dialog heading
```

Flat keys only (no nested objects in the JSON files).

## Component Setup

```tsx
import { useTranslation } from 'react-i18next'

export function MyComponent() {
  const { t } = useTranslation()
  return <button>{t('myComponent.buttonLabel')}</button>
}
```

## Interpolation

```tsx
// In locale file: "greeting": "Hello {{name}}"
t('greeting', { name: 'World' })
```

## Language Switcher

Language is persisted in `ConfigStore` at `ui.language` ('en' | 'de').
The dropdown lives in InfoSettingsView (Settings tab).
Changing language calls `i18n.changeLanguage()` for immediate effect.

## Files

| File | Purpose |
|------|---------|
| `src/renderer/i18n.ts` | i18next init, loads persisted language |
| `src/renderer/locales/en.json` | English strings (primary/fallback) |
| `src/renderer/locales/de.json` | German strings |
