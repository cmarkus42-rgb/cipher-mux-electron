# Formate

Referenz-Strukturen für wiederkehrende Deliverable-Formate. Wächst mit der Zeit — nach jedem Durchlauf, der ein neues Format produziert hat, entsteht hier eine Strukturdatei für das nächste Mal.

## Vorhandene Formate

- **`companion-als-ordner.md`** — Companion als numerierter Ordner mit Arbeits-Dokumenten statt monolithischer Datei. Entstanden 2026-04-19 im Wissenstransfer-Durchlauf.
- **`konzept-fuer-adressat.md`** — AI-first-Konzeptpapier nach XPRESS-Muster. Entstanden 2026-04 im XPRESS-Projekt.

## Noch nicht vorhandene Formate

Kandidaten, die beim nächsten passenden Durchlauf entstehen könnten:

- `sandbox-checkliste.md` — Was eine lauffähige AI-Use-Case-Sandbox enthält (Docker-Compose, n8n, Claude-Config, Persona-Skills, Testdaten, README zur Bedienung). Referenz: `XPRESS_Sandbox_Testset.zip`.
- `pitch-deck.md` — Struktur für Pitch-Folien.
- `strategiepapier.md` — Für interne Strategie-Deliverables ohne externen Adressaten.
- `business-use-case.md` — Einseitiger Angebots-Rahmen mit Preis, Abgrenzung, Investition.

Regel: Eine Format-Datei entsteht erst, wenn das Format **einmal tatsächlich gebaut** wurde. Keine Formate auf Vorrat.
