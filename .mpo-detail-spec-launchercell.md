# SP-3: LauncherCell + Grid UX

## Ziel
LauncherCell Unified-Popup aktivieren und Grid-Bugs fixen.

## Bugs

### B01 — LauncherCell Popup fehlt komplett (KRITISCH)
**Symptom:** Bei Klick auf leere Grid-Zelle erscheint alte Projektauswahl statt neuem Unified-Popup mit Presets/Pfad/Notes. 13/14 Testcases FAIL.
**Erwartung:** Leere Zelle zeigt LauncherCell-Component mit Unified-Popup: Preset-Auswahl (Orchestrator, MPO, Companion, Custom), Pfad-Picker, optionale Notes.
**Relevante Dateien:**
- `src/renderer/components/LauncherCell.tsx` — EXISTIERT, aber offenbar nicht eingebunden
- `src/renderer/components/SessionGrid.tsx` — Grid-Rendering, hier muss LauncherCell fuer leere Zellen genutzt werden
- `src/renderer/components/SessionCell.tsx` — Aktive Session-Zelle
- `src/renderer/components/UnifiedSessionDialog.tsx` — Moeglicherweise der alte Dialog
- `src/renderer/components/GridPlacementPopup.tsx` — Grid-Placement
- `src/renderer/components/ProjectCard.tsx` — Alte Projektauswahl?
- `src/renderer/hooks/useGrid.ts` — Grid-State

**Debugging-Ansatz:**
1. In SessionGrid.tsx pruefen: was rendert fuer leere Zellen? Wird LauncherCell.tsx verwendet?
2. LauncherCell.tsx lesen — ist das Feature implementiert oder nur Skeleton?
3. Falls implementiert: Einbindung in SessionGrid.tsx fixen
4. Falls Skeleton: Feature implementieren nach UnifiedSessionDialog als Referenz

### B08 — Grid-Placement ignoriert Doppelzellen (HOCH)
**Symptom:** Session landet hinter merged Cell statt an geklickter Position.
**Erwartung:** Placement respektiert Zell-Merging. Session landet an der Zelle die geklickt wurde.
**Relevante Dateien:**
- `src/renderer/hooks/useGrid.ts` — Grid-Logik, Merged-Cell-Tracking
- `src/renderer/components/GridPlacementPopup.tsx` — Placement-UI
- `src/shared/grid-types.ts` — Grid-Typen (Merged Cells etc.)

### B09 — Grid-Overlay bleibt haengen (HOCH)
**Symptom:** Nach Session-Platzierung schliesst sich Overlay nicht. App blockiert, Neustart noetig.
**Erwartung:** Overlay schliesst sich automatisch nach erfolgreicher Platzierung.
**Relevante Dateien:**
- `src/renderer/components/GridPlacementPopup.tsx` — Overlay-Lifecycle
- `src/renderer/components/SessionGrid.tsx` — Overlay-State

**Hinweis:** Vermutlich fehlt ein `onClose`-Call oder State-Reset nach Platzierung.

### B13 — Session-Popup in Zelle statt Overlay (MITTEL)
**Symptom:** Popup wird innerhalb der Grid-Zelle gerendert, wird abgeschnitten.
**Erwartung:** Popup schwebt als Overlay ueber dem Grid (z.B. Portal, position:fixed/absolute mit z-index).
**Relevante Dateien:**
- `src/renderer/components/LauncherCell.tsx` — Popup-Rendering
- `src/renderer/components/GridPlacementPopup.tsx` — Vergleichs-Referenz
- `src/renderer/styles/` — CSS

### B14 — Grid-Selektor Darstellung (MITTEL)
**Symptom:** Inhalt passt nicht zur Darstellung im Grid-Selektor.
**Relevante Dateien:**
- `src/renderer/components/GridPlacementPopup.tsx`
- `src/renderer/components/GridControls.tsx`

### B20 — Session-Rendering Zeilen fallen auseinander (NIEDRIG)
**Symptom:** Zeilen fallen manchmal auseinander in Grid-Zellen (xterm.js).
**Relevante Dateien:**
- `src/renderer/components/TerminalPane.tsx` — xterm.js Integration
- `src/renderer/hooks/useTerminal.ts` — Terminal-Hooks
- `src/renderer/components/SessionCell.tsx` — Cell-Sizing

**Hinweis:** Moeglicherweise ein Resize-Timing-Problem. xterm.js fit-Addon muss nach Layout-Aenderungen aufgerufen werden.

## Testcases

1. Leere Grid-Zelle klicken → LauncherCell Unified-Popup erscheint
2. Popup zeigt Preset-Buttons (Orchestrator, MPO, Companion, Custom)
3. Preset waehlen → Pfad-Picker (oder Default-Pfad)
4. Session startet an geklickter Position
5. Popup schliesst sich nach Start
6. Bei Doppelzelle: Klick auf sichtbare Zelle → Session an korrekter Position
7. Grid-Overlay schliesst sich nach Platzierung (kein Haengenbleiben)
8. Popup schwebt als Overlay, nicht in-cell abgeschnitten
9. Grid-Selektor: Darstellung korrekt, Inhalt passt
10. Terminal-Zeilen stabil in Grid-Zellen (kein Auseinanderfallen bei Resize)

## Qualitaets-Gate
- Testcases 1-9 PASS (TC10 ist niedrig-prio, best-effort)
- LauncherCell.tsx korrekt in SessionGrid eingebunden
- Kein Overlay-Haengen nach 5 Platzierungen hintereinander
- Popup-Rendering als Portal/Overlay, nicht in-cell
