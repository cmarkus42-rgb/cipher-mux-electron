# Detail-Spec: Worker 1 — Notes + Pin Fixes

## Bugs

### RT-1: NoteManager.save() verliert type-Feld (MUST)

**Datei:** `src/main/notes/note-manager.ts`
**Problem:** `save()` baut Frontmatter nur mit `title/tags/created/modified` neu auf. Custom-Felder wie `type: testcase` gehen verloren.
**Fix:** Beim Save die bestehenden Custom-Frontmatter-Felder erhalten. Entweder spezifisch:
```js
const fm = {
  title,
  tags: tags ?? existing?.info.tags ?? [],
  created: existing?.info.createdAt ?? now,
  modified: now,
  ...(existing?.info.noteType ? { type: existing.info.noteType } : {}),
}
```
Oder generischer: Alle Frontmatter-Felder aus dem bestehenden File lesen und unbekannte durchreichen.

**Testcase:** Note mit `type: testcase` erstellen, speichern, Note neu laden → `type` muss erhalten bleiben. TestcaseView muss nach Save weiterhin rendern.

### RT-8: Pin-Anzeige bleibt nach Unpin (SHOULD)

**Dateien:** `src/renderer/components/VoiceControl.tsx`, `src/renderer/hooks/useVoiceSession.ts`
**Problem:** Funktional korrekt (STT folgt Fokus nach Unpin), aber UI zeigt weiterhin die alte gepinnte Session an.
**Fix:** Beim Unpin den UI-State (`pinnedSession` o.ae.) zuruecksetzen.

**Testcase:** Session pinnen → Pin entfernen → UI zeigt keine gepinnte Session mehr. STT folgt dem Fokus.
