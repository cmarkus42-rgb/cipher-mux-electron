# SP-4: Voice COM

## Ziel
Voice COM-Modus reparieren: Background-Spawn, Enter/Submit nach STT, STT-Pausierung bei BugReport. Voice-Preset aus Grid entfernen. Graceful Shutdown.

## Kontext
SP-2 (MCP Infra) ist abgeschlossen — Companion hat jetzt MCP-Tools. Voice-Relay braucht diese Tools fuer die Kommunikation.

## Bugs

### B03 — Voice COM: Kein Background-Spawn (KRITISCH)
**Symptom:** Bei COM-Aktivierung oeffnet sich Grid-Selektor statt automatischem Background-Spawn. Claude startet nicht automatisch in Voice-Relay.
**Erwartung:** COM-Button in StatusBar → Voice-Relay-Session startet automatisch im Hintergrund (nicht im Grid). Kein Grid-Selektor.
**Relevante Dateien:**
- `src/renderer/components/VoiceControl.tsx` — COM-Button Handler
- `src/renderer/components/StatusBar.tsx` — StatusBar mit Voice-Controls
- `src/main/voice/voice-manager.ts` — Voice-Lifecycle
- `src/main/voice/conversation-engine.ts` — Conversation-Engine
- `src/main/session/voice-relay-template.ts` — Voice-Relay Session-Template
- `src/main/session/session-manager.ts` — Session-Erstellung
- `src/renderer/hooks/useVoiceSession.ts` — Voice-Session-Hook

**Debugging-Ansatz:**
1. Was passiert wenn COM aktiviert wird? Welcher Handler wird aufgerufen?
2. Wird session-manager.startEntity('voice-relay') aufgerufen oder ein Grid-Placement getriggert?
3. voice-relay-template.ts pruefen — ist es als Background-Session konfiguriert?

### B04 — Voice COM: Kein Enter nach STT (KRITISCH)
**Symptom:** Text wird an Voice-Relay gesendet, aber nicht submitted. Claude antwortet nie → kein TTS.
**Erwartung:** Nach STT-Transkription wird Text + Enter an die Voice-Relay-Session gesendet.
**Relevante Dateien:**
- `src/main/voice/stt-router.ts` — STT-Output-Routing
- `src/main/voice/voice-input-router.ts` — Input-Routing
- `src/main/voice/voice-manager.ts` — Voice-Lifecycle
- `src/main/tmux/tmux-manager.ts` — tmux send-keys (Enter muss mit!)

**Hinweis:** Bekanntes Pattern — nach tmux send-keys muss ein separates Enter gesendet werden. Siehe auch Memory-Feedback "tmux Enter Feedback".

### B12 — STT-Konflikt mit BugReport (MITTEL)
**Symptom:** App-STT laeuft weiter wenn BugReport geoeffnet wird. Text landet in BugReport-Bubbles.
**Erwartung:** STT wird bei BugReport-Open automatisch pausiert, bei Close wieder aktiviert.
**Relevante Dateien:**
- `src/main/voice/voice-manager.ts` — Voice-State
- `src/main/voice/bugreport-interview.ts` — BugReport Voice-Integration
- `src/main/bugreport/bugreport-manager.ts` — BugReport-Lifecycle
- `src/renderer/components/BugreportDialog.tsx` — BugReport-UI
- `src/renderer/voice/use-voice-bugreport.ts` — BugReport Voice-Hook

### FR2 — Voice-Preset aus Grid-Popup entfernen
**Beschreibung:** Voice soll nur ueber COM-Button in StatusBar steuerbar sein, nicht als Grid-Preset.
**Relevante Dateien:**
- `src/renderer/components/LauncherCell.tsx` — Preset-Liste (Voice raus)
- `src/main/session/entity-registry.ts` — Entity-Definitionen

### FR3 — Voice-Relay graceful Shutdown
**Beschreibung:** Bei COM→STT Wechsel: Notes sichern, Session schliessen (ggf. 10min Timeout).
**Relevante Dateien:**
- `src/main/voice/voice-manager.ts` — Mode-Wechsel
- `src/main/voice/conversation-engine.ts` — Conversation-Lifecycle
- `src/main/session/session-manager.ts` — Session-Kill

## Testcases

1. StatusBar: COM-Button klicken → Voice-Relay startet im Hintergrund (kein Grid-Selektor)
2. Voice-Relay laeuft → Sidebar zeigt lila Glow
3. Sprechen im COM-Modus → Text wird an Voice-Relay gesendet MIT Enter
4. Claude in Voice-Relay antwortet → TTS spielt Antwort ab
5. BugReport oeffnen waehrend STT aktiv → STT pausiert
6. BugReport schliessen → STT resumed
7. LauncherCell Popup → kein Voice-Preset in der Liste
8. COM→STT wechseln → Voice-Relay-Session wird graceful beendet (Notes gesichert)
9. COM→OFF → Voice-Relay beendet
